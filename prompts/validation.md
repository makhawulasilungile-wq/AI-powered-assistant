# Responsible AI Validation Prompt

Review the generated resume content.

Check for:

1. Fabricated qualifications
2. Fabricated work experience
3. Fabricated achievements
4. Unsupported skills
5. False statistics
6. Discriminatory language
7. Misleading claims
8. Privacy concerns
9. Grammar problems
10. ATS readability problems

For each issue provide:

- Issue
- Risk
- Recommended correction

End by reminding the user to verify the final content before submitting it.
