# Prompt Engineering Strategy

## Basic Prompt

Write a professional summary for my CV.

## Improved Prompt

Write a 3–5 sentence professional resume summary using my qualification, experience, skills and target position. Use professional language and relevant keywords. Do not invent information.

## Structured Prompt

### Role
You are a professional AI Resume Assistant.

### Context
The user is applying for a specific position and needs a professional resume summary.

### Inputs
- Qualification
- Work experience
- Skills
- Target position
- Industry

### Task
Create a concise professional resume summary.

### Constraints
- Use only information supplied by the user.
- Do not fabricate information.
- Use professional language.
- Include relevant keywords.
- Keep the summary concise.

### Output
Provide one polished resume summary followed by a short list of keywords used.

## Prompt Refinement

AI output should be reviewed for:

- Accuracy
- Relevance
- Professional tone
- Grammar
- Conciseness
- ATS compatibility
- Job-description alignment
- Fabricated information

The final output must always be verified by the user.
