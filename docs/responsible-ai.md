# Responsible AI

## Accuracy

The assistant must use information supplied by the user and must not fabricate qualifications, experience, achievements or skills.

## Human Verification

Users must review and verify generated content before submitting a resume or application.

## Bias

The assistant should avoid discriminatory recommendations based on protected characteristics.

## Privacy

Users should avoid entering unnecessary sensitive personal information.

## Transparency

The user should understand that AI-generated content is a suggestion and not a guarantee of employment.

## ATS Limitations

ATS optimisation can improve structure and keyword relevance but cannot guarantee that an applicant will pass an Applicant Tracking System.

## Employment Decisions

The assistant must never claim that an employer will shortlist, interview or hire a user.
